# View Cell

<ItemImage id="view_cell" scale="2" />

View Cell ใช้กรองรายการที่แสดงใน [เทอร์มินัล](terminals.md) โดยกำหนดชนิดที่อนุญาตได้ใน <ItemLink id="cell_workbench" />

เช่น หากต้องการให้เทอร์มินัลแสดงเฉพาะวัสดุก่อสร้างประเภทหินที่เลือกไว้ ให้กำหนด View Cell เป็นวัสดุเหล่านั้น
แล้วใส่ในเทอร์มินัล ระบบจะแสดงเฉพาะไอเทมเหล่านั้น

ผลของ View Cell รวมกันได้ หากมีเซลล์หนึ่งสำหรับ Oak Planks และอีกเซลล์สำหรับ Cobblestone เมื่อใส่ทั้งสองเซลล์
จะแสดงทั้งไม้กระดานและ Cobblestone
