# The Memory Card

<ItemImage id="memory_card" scale="4" />

Memory Card ใช้คัดลอกและวางการตั้งค่าระหว่าง [อุปกรณ์](../ae2-mechanics/devices.md) AE2 และเชื่อมโยง
[P2P Tunnel](p2p_tunnels.md) อีกทั้งใช้ใส่ [การ์ดอัปเกรด](upgrade_cards.md) ลงในอุปกรณ์ได้

- Shift+คลิกขวาเพื่อคัดลอกการตั้งค่าหรือสร้างความถี่เชื่อมโยง P2P ใหม่
- คลิกขวาเพื่อวางการตั้งค่า การ์ดอัปเกรด หรือความถี่เชื่อมโยง
