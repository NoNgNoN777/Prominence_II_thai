ส่วนเสริมภาษาไทยม็อดเทค — Prominence II 4.1.3 / Minecraft 1.20.1 Fabric

มีคำแปล Create และส่วนเสริม, Ponder, AE2/ExtendedAE และส่วนเสริม, Modern Industrialization, Tech Reborn, Powah, Kibe, Ad Astra พร้อมคู่มือและเกร็ดความรู้
คงชื่อเครื่องจักร ไอเทม วัสดุ และหน่วยเป็นอังกฤษ

ติดตั้ง:
1. ปิด Minecraft ก่อน และสำรองไฟล์ config/fancymenu/assets/tips.txt กับ config/fancymenu/customization/Esc Menu.txt และ LoadingScreen.txt
2. ชุดเสริม Addon ใช้วางทับชุดภาษาไทยเดิม ไม่รวมม็อดแพ็กตัวเกมหรือฟอนต์ ส่วน Pack_For_Friends รวมชุดภาษาไทยเดิมจาก repo และส่วนเสริมนี้แล้ว
3. แตก ZIP แล้วคัดลอก config และ resourcepacks ไปยัง instance ที่มี mods/config อย่าวางโฟลเดอร์ครอบ ZIP ซ้อนอีกชั้น
4. ใช้ภาษาเกม English (US) ตามเดิม หรือเลือกภาษาไทยได้ เปิด ZZZ_Prominence_II_Thai_Tech.zip ให้อยู่เหนือ ZZ_Prominence_II_Thai_RPG.zip และแพ็กแปลอื่น หาก Paxi โหลดให้อัตโนมัติ ไม่ต้องเปิดสำเนาที่สองซ้ำ
5. ใช้ฟอนต์ไทยเดิม ไม่ได้แนบฟอนต์เพิ่ม ส่วนนี้เป็นของฝั่งผู้เล่น ไม่ต้องวางบน dedicated server

ก่อนทับ FancyMenu โปรดตรวจว่าเป็น Prominence II 4.1.3 และไม่มีการแก้เมนูส่วนตัว ไฟล์ใน customization เป็น layout เต็มจาก instance ต้นฉบับที่แก้เฉพาะหัวข้อ หากเป็นคนละเวอร์ชัน ให้คัดลอกเฉพาะข้อความหัวข้อและ tips แทนการทับ layout ทั้งไฟล์
คู่มือ AE2 ใช้ resource path ร่วมทุกภาษา จึงแสดงเนื้อหาไทยแม้เลือกภาษาอื่น เก็บหัวข้ออังกฤษเดิมเพื่อรักษาลิงก์ในคู่มือ และวางหัวข้อไทยต่อท้ายเมื่อเป็นคำทั่วไป

ตรวจในเกมหลังติดตั้ง:
- หยุดเกม: เกร็ดความรู้ซ้ายล่างและหัวข้อรู้หรือไม่เป็นไทย
- ชี้ Large Cogwheel: ข้อความกดปุ่มค้างเพื่อดู Ponder เป็นไทย โดยชื่อไอเทมยังอังกฤษ
- เปิด Ponder ของ Valve Handle และ Accumulator: คำอธิบายและปุ่มเป็นไทย
- เปิดคู่มือ Extended Inscriber: ข้อความทำพร้อมกัน 4 งานและคำแนะนำกองละ 1 เป็นไทย
- เปิดคู่มือ AE2, MI, Ad Astra ลองลิงก์ข้ามหน้า รูป สูตร และหน้าเนื้อหายาว
- เช็ก tooltip ที่มีตัวเลข/เปอร์เซ็นต์ ไม่มี placeholder ค้างหรือ Format error และฟอนต์ไม่ล้น

ย้อนกลับ: ปิดเกม ลบ ZZZ_Prominence_II_Thai_Tech.zip จาก resourcepacks และ config/paxi/resourcepacks แล้วคืน FancyMenu 3 ไฟล์จากสำรอง ชุดแปล RPG เดิมยังอยู่
