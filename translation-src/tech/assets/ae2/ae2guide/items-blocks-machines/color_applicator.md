# The Color Applicator

<ItemImage id="color_applicator" scale="4" />

Color Applicator ใช้ทาสีบล็อกที่เปลี่ยนสีได้ เช่น [สาย](cables.md), Wool, Terracotta, Glass และ Concrete โดยใช้
[Paintball](paintballs.md) หรือสีย้อม และใช้ Snowball ล้างสีออกจากสายและลบรอย Paintball บนบล็อกได้

ชาร์จพลังงานกลับได้ใน <ItemLink id="charger" />

Color Applicator ทำงานเหมือน [Storage Cell](storage_cells.md) วิธีเติมที่เก็บสีที่ง่ายที่สุดคือใส่
Color Applicator ในช่อง Storage Cell ของ <ItemLink id="chest" />

คลิกขวาเพื่อทาสี และกด Shift พร้อมหมุนล้อเมาส์เพื่อสลับ Paintball และสีย้อมที่เก็บไว้

## Upgrades

อัปเกรด

Color Applicator รองรับ [อัปเกรด](upgrade_cards.md) ต่อไปนี้ โดยใส่ผ่าน <ItemLink id="cell_workbench" />:

*   <ItemLink id="equal_distribution_card" /> แบ่งพื้นที่ไบต์ของเซลล์ให้แต่ละชนิดเท่ากัน เพื่อไม่ให้ชนิดเดียวกินพื้นที่ทั้งเซลล์
*   <ItemLink id="void_card" /> ทำลายไอเทมที่ใส่เข้าเมื่อเซลล์เต็ม (หรือเมื่อพื้นที่ที่แบ่งให้ชนิดนั้นเต็ม
    หากใช้ Equal Distribution Card) ควรกำหนดชนิดที่อนุญาตให้เก็บอย่างระมัดระวัง!
*   <ItemLink id="energy_card" /> เพิ่มความจุแบตเตอรี่
