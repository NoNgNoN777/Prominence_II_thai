# The Wireless Access Point

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

ทำให้เข้าถึงระบบแบบไร้สายผ่าน <ItemLink id="wireless_terminal" /> ได้
ระยะและการใช้พลังงานขึ้นอยู่กับจำนวน <ItemLink id="wireless_booster" /> ที่ติดตั้ง

เครือข่ายหนึ่งมี Wireless Access Point ได้ไม่จำกัดจำนวน และแต่ละเครื่องติดตั้ง
<ItemLink id="wireless_booster" /> ได้หลายชิ้น คุณจึงปรับผังการติดตั้งเพื่อให้สมดุลระหว่าง
การใช้พลังงานกับระยะครอบคลุมได้

ต้องใช้ [ช่องสัญญาณ](../ae2-mechanics/channels.md)

ใช้ผูก [เทอร์มินัลไร้สาย](wireless_terminals.md) ด้วย
