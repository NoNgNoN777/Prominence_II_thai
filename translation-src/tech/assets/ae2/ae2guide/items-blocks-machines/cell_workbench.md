# The Cell Workbench

<BlockImage id="cell_workbench" scale="8" />

Cell Workbench ใช้ตั้งค่า [Storage Cell](storage_cells.md) และ <ItemLink id="view_cell" />

คุณเพิ่ม [การ์ดอัปเกรด](upgrade_cards.md) และกำหนดรายการชนิดที่อนุญาต เพื่อกรองสิ่งที่เซลล์จะจัดเก็บได้

ลากไอเทมและของเหลวจาก JEI/REI มาใส่ช่องได้ แม้คุณจะไม่มีไอเทมนั้นอยู่จริง

คลิกขวาด้วยภาชนะของเหลว (เช่น Bucket หรือถังของเหลว) เพื่อกำหนดของเหลวนั้นเป็นตัวกรอง แทนที่จะกรองตัวไอเทมภาชนะ

## Settings

การตั้งค่า

มุมซ้ายบนของ Cell Workbench มีปุ่มอยู่หลายปุ่ม:

*   กำหนดชนิดที่เซลล์อนุญาตให้เก็บตามของที่อยู่ภายในปัจจุบันได้
*   ล้างรายการชนิดที่เซลล์อนุญาตให้เก็บได้
*   ตั้งให้โต๊ะเก็บรายการกรองไว้เมื่อนำเซลล์ออกได้ เพื่อคัดลอกการตั้งค่าระหว่างเซลล์
