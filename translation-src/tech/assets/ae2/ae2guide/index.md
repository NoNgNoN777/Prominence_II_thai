# What is Applied Energistics 2?

Applied Energistics 2 คืออะไร?

Applied Energistics 2 เพิ่มส่วนประกอบและกลไกสำหรับระบบขนส่งและจัดเก็บ คุณแทนห้อง
ที่เต็มไปด้วยหีบมหาศาลได้ด้วยเครือข่าย ME กะทัดรัด แต่นั่นเป็นเพียงจุดเริ่มต้น
Applied Energistics ออกแบบให้ทำงานร่วมกับม็อดอื่นในแพ็กและทำให้เป็นอัตโนมัติ คุณตั้งระบบให้
คลิกครั้งเดียวแล้วคราฟต์ทุกขั้นก่อนหน้า (รวมถึงผลลัพธ์สุดท้าย) ในสายคราฟต์ซับซ้อนได้ หรือรักษา
จำนวนไอเทมในสต็อกโดยคราฟต์เพิ่มเมื่อจำเป็น หรือเพียงขนส่งไอเทมไปทั่วฐาน
