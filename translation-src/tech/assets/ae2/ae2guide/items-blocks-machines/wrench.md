# Wrenches

ประแจ

<Row>
  <ItemImage id="certus_quartz_wrench" scale="4" />

  <ItemImage id="nether_quartz_wrench" scale="4" />
</Row>

Wrench ใช้หมุนอุปกรณ์ AE2 (คลิกขวา) และถอดบล็อก AE2 (Shift+คลิกขวา)
ถอด [ชิ้นส่วนย่อย](../ae2-mechanics/cable-subparts.md) ออกจากสายได้โดยไม่ต้องทำลายทุกอย่างบนสาย
(หรือถอดสายโดยไม่ทำลายชิ้นส่วนย่อยก็ได้)

บล็อก AE2 หลายชนิดหมุนได้ ดังนั้นแม้คู่มือจะไม่ได้ระบุว่าสิ่งใดหมุนได้ ก็ไม่ได้หมายความว่าจะหมุนไม่ได้
