# Pattern Modifier

Pattern Modifier เป็นเครื่องมือแก้ไขแพตเทิร์นจำนวนมากพร้อมกัน

<ItemImage id="extendedae:pattern_modifier" scale="4"></ItemImage>

คลิกขวาเพื่อเปิดหน้าจอใช้งาน

## Multiply Mode

โหมดคูณจำนวน

คลิกปุ่มที่ต้องการเพื่อคูณหรือหารจำนวนวัตถุดิบและผลผลิตในแพตเทิร์นแปรรูปด้วยค่า x 

![PM](../pic/pm.png)

แพตเทิร์นเดิม:

![PM1](../pic/pm1.png)

หลังคูณ 10:

![PM2](../pic/pm2.png)

คลิกปุ่มล้างเพื่อลบเนื้อหาแพตเทิร์นทั้งหมดและเปลี่ยนเป็นแพตเทิร์นเปล่าได้ด้วย

### Notes:

หมายเหตุ:

 - ปุ่มหารใช้ได้เฉพาะเมื่อหารจำนวนลงตัว เช่น ปุ่ม ÷2 จะใช้ไม่ได้หากแพตเทิร์นต้องใช้ Cobblestone 3 ชิ้น
เพราะ 3÷2 เท่ากับ 1.5

 - ปุ่มคูณมีเพดานที่ 999999 จึงเพิ่มจำนวนวัตถุดิบชนิดใดชนิดหนึ่งเกินค่านี้ไม่ได้

## Replace Mode

โหมดแทนที่

แทนที่วัตถุดิบหรือผลผลิตที่กำหนดในแพตเทิร์นแปรรูปด้วยไอเทมอื่น

![PM3](../pic/pm4.png)

ช่อง A คือสิ่งที่จะถูกแทนที่ ส่วนช่อง B คือสิ่งที่จะใช้แทน

ตัวอย่างการตั้งค่าต่อไปนี้จะแทนที่ Planks ด้วย Coal

![PM4](../pic/pm6.png)

![PM5](../pic/pm5.png)

คลิกปุ่มแทนที่เพื่อเริ่มเปลี่ยนรายการ

![PM6](../pic/pm7.png)

## Clone Mode

โหมดทำสำเนา

ใช้โหมดนี้ทำสำเนาแพตเทิร์นที่ใส่ไว้ได้
