# ผลตรวจคำแปลม็อดเทค

- ตรวจ/จัดการรายการภาษา 6,599 รายการใน 21 namespaces รวม Ponder library โดยมีชื่อเครื่องจักร วัสดุ หน่วย และรหัสที่ตั้งใจคงอังกฤษ
- เพิ่ม English name overrides 5,733 คีย์ลงทั้ง en_us/th_th เพื่อไม่ให้ชื่อไอเทมเปลี่ยนเมื่อเลือกภาษาไทย ตัวเลขนี้ไม่ใช่จำนวนประโยคที่แปล
- Markdown AE2 120, ExtendedAE 27; Patchouli MI 40, Ad Astra 35; รวม 222 ไฟล์ต้นฉบับภาษาอังกฤษ
- Patchouli มีสำเนา th_th เพิ่ม 75 ไฟล์ ใช้เนื้อหาเดียวกัน ไม่ได้นับเป็นงานแปลเพิ่ม
- FancyMenu tips 17 ข้อ และหัวข้อใน pause/loading layout 2 ไฟล์

## ตรวจแล้ว
- mtt validate: errors 0, warnings 1614 หลังเพิ่ม UI Ponder และใช้ข้อแก้รอบสอง
- คำเตือนส่วนใหญ่เป็นชื่อ/หน่วยที่คงอังกฤษ มี 64 คำเตือนรูปแบบ %d หรือเปอร์เซ็นต์จากต้นฉบับที่คงไว้เพื่อไม่เปลี่ยนชนิด argument; ตัวตรวจชื่อข้ามม็อดมี false positive ของคำทั่วไป ดูรายงานแยก
- คู่มือ 222 ไฟล์: โครงสร้าง JSON, Patchouli macros, JSX, resource IDs/attributes, links, technical frontmatter และหัวข้อเดิมสำหรับ anchors ผ่าน
- ตรวจความหมายข้อความยาวและประเด็นจำนวน/เงื่อนไขโดยรอบสอง พร้อมแก้ประวัติคำแปลเดิม 406 จุดและชื่อ/UI เพิ่ม 43 จุด ไม่ใช่การรับประกันว่าทุกประโยคไม่มีข้อบกพร่อง
- เพิ่มเทสต์สกิลและรันรวม 16 tests ผ่าน: การรักษา guide references และประวัติ memory ระหว่าง import รวม install recovery เดิม

## สิ่งที่ต้องตรวจในเกม
ยังไม่ได้ติดตั้ง instance จึงยังไม่ได้ยืนยันฟอนต์/ข้อความล้น การเลือกแพ็ก priority การ parse Markdown ในเกม ลิงก์สูตร และ placeholder ที่ caller ใช้จริง
ให้ตรวจตาม วิธีลงส่วนเสริมม็อดเทค.txt หลังปิดเกม สำรอง และติดตั้ง
การติดตั้งแบบอัตโนมัติต้องใช้ build ที่รวม guide/config overlay และสำรองไฟล์ FancyMenu ทั้ง 3 ไฟล์ ห้ามใช้ mtt build เดิมที่มีเฉพาะ lang แล้วถือว่าครบ

- AE2 channels ตาราง x3 เขียน Dense Cable 92 ช่อง คงเลขเดิมไว้ ยังไม่แก้เป็น 96 โดยเดา
- ExtendedAE Crystal Fixer ใช้ navigation title Growth Chamber แต่ body Fixer คงชื่อจากต้นฉบับ
