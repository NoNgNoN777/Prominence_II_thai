# The Storage Bus

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/storage_bus.snbt" />
</GameScene>

เคยอยาก เก็บ กองหีบอันยุ่งเหยิงไว้ แทนที่จะเปลี่ยนเป็นระบบที่เข้าท่าไหม? ขอเสนอ Storage Bus!

Storage Bus เปลี่ยนช่องเก็บของที่สัมผัสอยู่ให้เป็น [ที่เก็บของเครือข่าย](../ae2-mechanics/import-export-storage.md)
โดยให้เครือข่ายเห็นของภายใน และใส่หรือดึงจากช่องเก็บของนั้น
ตามที่ [อุปกรณ์](../ae2-mechanics/devices.md) ต่าง ๆ ใส่หรือดึงจากที่เก็บของเครือข่าย

ตามแนวคิดของ AE2 ที่ให้กลไกใหม่เกิดจากปฏิสัมพันธ์ของ [อุปกรณ์](../ae2-mechanics/devices.md) ต่าง ๆ คุณจึง
ไม่ จำเป็น ต้องใช้ Storage Bus เพื่อ จัดเก็บ เสมอไป ใช้ [เครือข่ายย่อย](../ae2-mechanics/subnetworks.md)
ทำให้ Storage Bus หนึ่งหรือหลายตัวเป็นที่เก็บ เพียงอย่างเดียว ในเครือข่าย แล้วใช้มันเป็นต้นทางหรือปลายทาง
ขนส่งไอเทมได้ (ดู ["เครือข่ายย่อยแบบท่อ"](../example-setups/pipe-subnet.md))

เป็น [ชิ้นส่วนย่อยของสาย](../ae2-mechanics/cable-subparts.md)

## Filtering

การกรอง

ค่าเริ่มต้นบัสจะเก็บทุกอย่าง ไอเทมในช่องกรองทำหน้าที่เป็นรายการอนุญาต
ให้เก็บเฉพาะไอเทมที่ระบุไว้

ลากไอเทมและของเหลวจาก JEI/REI มาใส่ช่องได้ แม้คุณจะไม่มีไอเทมนั้นอยู่จริง

คลิกขวาด้วยภาชนะของเหลว (เช่น Bucket หรือถังของเหลว) เพื่อกำหนดของเหลวนั้นเป็นตัวกรอง แทนที่จะกรองตัวไอเทมภาชนะ

## Priority

ลำดับความสำคัญ

ตั้งลำดับความสำคัญโดยคลิกประแจมุมขวาบนของหน้าจอ
ไอเทมที่เข้าสู่เครือข่ายจะเลือกที่เก็บที่มีลำดับสูงสุดก่อน
หากสองแห่งมีลำดับเท่ากัน จะเลือกแห่งที่มีไอเทมชนิดนั้นอยู่แล้ว
ก่อนที่เก็บอื่น ที่เก็บที่ตั้งตัวกรองไว้จะถือว่ามีไอเทมนั้นอยู่แล้ว
เมื่ออยู่ในกลุ่มลำดับเดียวกัน การดึงไอเทมออกจะเริ่มจาก
ที่เก็บที่มีลำดับต่ำสุด ระบบนี้ทำให้เมื่อมีการใส่และดึงของจากเครือข่าย
ที่เก็บลำดับสูงจะค่อย ๆ เต็ม ส่วนที่เก็บลำดับต่ำจะค่อย ๆ ว่าง

## Settings

การตั้งค่า

*   กำหนดชนิดที่บัสอนุญาตให้เก็บตามของที่อยู่ในช่องเก็บของข้างเคียงปัจจุบันได้
*   อนุญาตหรือปิดกั้นไม่ให้เครือข่ายเห็นไอเทมข้างเคียงที่บัสดึงออกไม่ได้
    (เช่น Storage Bus ดึงจากช่องขาเข้ากลางของ <ItemLink id="inscriber" /> ไม่ได้)
*   เลือกให้กรองทั้งการใส่และดึง หรือกรองเฉพาะการใส่ได้
*   ตั้งบัสให้ทำงานสองทิศทาง รับเข้าอย่างเดียว หรือดึงออกอย่างเดียวได้

## Upgrades

อัปเกรด

Storage Bus รองรับ [อัปเกรด](upgrade_cards.md) ต่อไปนี้:

*   <ItemLink id="capacity_card" /> เพิ่มจำนวนช่องกรอง
*   <ItemLink id="fuzzy_card" /> ให้กรองตามระดับความเสียหายและ/หรือไม่สนใจ NBT ของไอเทม
*   <ItemLink id="inverter_card" /> เปลี่ยนจากรายการอนุญาตเป็นรายการปฏิเสธ
*   <ItemLink id="void_card" /> ทำลายไอเทมที่ใส่เข้าเมื่อช่องเก็บของที่ติดอยู่เต็ม ช่วยป้องกันฟาร์มตัน ควรกำหนดชนิดที่อนุญาตให้เก็บอย่างระมัดระวัง!
