# แผนที่อนุมัติแล้ว
ผู้ใช้อนุมัติในแชตให้แปลม็อดเทคทั้งม็อด เกร็ด FancyMenu และคู่มือ พร้อมตรวจซ้ำ ไม่ commit/push
Instance: D:/minecraft/Instances/Prominence_ II Hasturian Era, MC 1.20.1, Fabric, pack 4.1.3
ขอบเขต: namespaces ใน project.json; UI/tooltip/Ponder/advancement/คู่มือ; ไม่แปลเควสต์และผังสกิลซ้ำ; ชื่อไอเทม เครื่องจักร คลาส วัสดุ หน่วย คงอังกฤษ
การตั้งค่าฝั่ง config แยกเป็นงานรองตามแผนเดิม เน้นข้อความผู้เล่นก่อน; ค่า default delivery resourcepacks+paxi, en_us และ th_th, ไม่แนบฟอนต์หรือ jar เพิ่ม ไม่สร้าง server pack เพราะเป็นเนื้อหาฝั่ง client
ต้นฉบับแพ็กหลักจาก GitHub; ใช้ exact source memory และ native th_th แล้วตรวจ placeholder ก่อนรับ
คู่มือ Markdown, Patchouli, FancyMenu ต้องทำและตรวจแยกจาก mtt; ไม่ถือว่างานเสร็จเพียงเพราะ mtt status ผ่าน
ปลายทางต้นฉบับและแพ็กเสริม: repo Prominence_II_thai; work เก็บรายการ source/batches/reports
ไม่ติดตั้ง instance จนเกมปิดและได้อนุมัติการติดตั้ง; สร้างแพ็กพร้อมติดตั้งก่อน
