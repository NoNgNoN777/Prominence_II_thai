# Network Tool

<ItemImage id="network_tool" scale="4" />

Network Tool คือ [Wrench](wrench.md) ที่ดัดแปลงให้แสดงข้อมูลวินิจฉัยเครือข่ายและเก็บ [การ์ดอัปเกรด](upgrade_cards.md) ได้
ยังคงถอดสิ่งต่าง ๆ และดึง [ชิ้นส่วนย่อย](../ae2-mechanics/cable-subparts.md) ออกจากสายได้อย่างรวดเร็วเหมือน Wrench
แต่ใช้หมุนสิ่งต่าง ๆ ไม่ได้

มี 9 ช่องสำหรับเก็บ [การ์ดอัปเกรด](upgrade_cards.md) ซึ่งจะพร้อมใช้ในหน้าจออุปกรณ์ AE2 ทุกชิ้น
ตราบใดที่เครื่องมืออยู่ที่ใดก็ได้ในช่องเก็บของของคุณ

คลิกขวาที่ส่วนใดของเครือข่ายเพื่อเปิดหน้าต่างข้อมูลวินิจฉัย เหมือนคลิกขวาที่ <ItemLink id="controller" />
หน้าต่างนี้แสดง

*   จำนวนช่องสัญญาณที่เครือข่ายใช้อยู่
*   ตัวเลือกหน่วยพลังงานส่วนกลางระหว่าง AE กับ E/FE
*   [พลังงาน](../ae2-mechanics/energy.md) ที่เก็บในเครือข่าย และความจุพลังงานสูงสุด
*   ปริมาณพลังงานขาเข้าและพลังงานที่เครือข่ายใช้
*   รายการ [อุปกรณ์](../ae2-mechanics/devices.md) และส่วนประกอบทั้งหมดในเครือข่าย

หน้าต่างนี้ยังช่วยตรวจว่าสายหรืออุปกรณ์สองชิ้นอยู่ในเครือข่ายเดียวกันหรือไม่ เมื่อทดลองจัด
[เครือข่ายย่อย](../ae2-mechanics/subnetworks.md)
