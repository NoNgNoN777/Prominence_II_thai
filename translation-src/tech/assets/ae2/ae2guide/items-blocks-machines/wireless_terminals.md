# Wireless Terminals

เทอร์มินัลไร้สาย

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

เทอร์มินัลไร้สายเป็น [เทอร์มินัล](terminals.md) แบบมีสายรุ่นพกพา หน้าจอเหมือนรุ่นมีสายทุกประการ
แต่เปลี่ยนช่อง <ItemLink id="view_cell" /> เป็นช่อง [การ์ดอัปเกรด](upgrade_cards.md)

จับคู่กับเครือข่ายโดยใส่เทอร์มินัลในช่องขวาบนของ <ItemLink id="wireless_access_point" />
ที่เชื่อมกับเครือข่ายนั้น (ช่องที่มีรูปเทอร์มินัลไร้สายและลูกศรอยู่ด้านล่าง)

ต้องอยู่ในระยะของ <ItemLink id="wireless_access_point" /> จึงจะทำงาน

ชาร์จพลังงานกลับได้ใน <ItemLink id="charger" />

# Wireless Crafting Terminal

<ItemImage id="wireless_crafting_terminal" scale="4" />
